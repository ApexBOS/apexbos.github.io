  • Backup အရင်လုပ်ပါ — ဆက်တင် → Backup။ ဖိုင်ကို ဖုန်းအပြင် (Drive, USB…) တွင်လည်း သိမ်းထားပါ။Make a Backup first — Settings → Backup. Keep a copy off the phone too (Drive, USB…).
  • လုပ်ငန်းတစ်ခု၏ စက်အားလုံးကို အတူတူ အပ်ဒိတ်လုပ်ပါ — ဗားရှင်း မတူသော စက်များသည် ဒေတာ ကောင်းစွာ မစင့်ခ်နိုင်ပါ။Update every device in a business together — devices on different versions may not sync properly.

ထည့်သွင်းနည်းHow to install

  1. အပေါ်က ခလုတ်ဖြင့် APK ကို ဒေါင်းလုဒ်လုပ်ပါ။Download the APK with the button above.
  2. ဒေါင်းလုဒ်ပြီးသော ဖိုင်ကို ဖွင့်ပါ။ ဖုန်းက "အမည်မသိ အက်ပ်များ ထည့်သွင်းခွင့်" (Install unknown apps) မေးလျှင် ဤ browser / ဖိုင်မန်နေဂျာ အတွက် ခွင့်ပြု ကို ဖွင့်ပြီး ပြန်လာပါ။Open the downloaded file. If the phone asks about "Install unknown apps", turn on Allow for this browser / file manager, then go back.
  3. ထည့်သွင်း (Install / Update) ကို နှိပ်ပါ။ ဒေတာများ ဆက်ရှိနေပါမည်။Tap Install (or Update). Your data stays on the phone.
  4. ApexBOS ကို ဖွင့်ပြီး ဆက်တင် → အကြောင်း တွင် ဗားရှင်း 0.2.23 ဖြစ်ကြောင်း စစ်ပါ။Open ApexBOS and check Settings → About shows version 0.2.23.

စမ်းသပ်ဖုန်းများ — တစ်ကြိမ်သာTest phones — one time only

ဗားရှင်းဟောင်း စမ်းသပ် (debug) build သုံးနေသော ဖုန်းတွင် "App not installed" ပြလျှင် —If a phone on an old test (debug) build says "App not installed":

  1. ဗားရှင်းဟောင်းထဲတွင် Backup လုပ်ပြီး ဖိုင်နှင့် စကားဝှက်ကို သိမ်းပါ။Make a Backup in the old app; keep the file and its password.
  2. ApexBOS ဟောင်းကို ဖြုတ်ပါ (Uninstall)။Uninstall the old ApexBOS.
  3. APK အသစ်ကို ထည့်သွင်းပါ။Install the new APK.
  4. Backup ဖိုင်ဖြင့် Restore လုပ်ပါ။Restore from the Backup file.
  5. စက်များ → ဤစက်ကို အခြားစက်များနှင့် ပြန်ချိတ်ပါ။Devices → pair this device with the others again.
