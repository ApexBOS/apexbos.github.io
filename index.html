  1. အပေါ်က ခလုတ်ဖြင့် APK ကို ဒေါင်းလုဒ်လုပ်ပါ။Download the APK with the button above.
  2. ဒေါင်းလုဒ်ပြီးသော ဖိုင်ကို ဖွင့်ပါ။ ဖုန်းက "အမည်မသိ အက်ပ်များ ထည့်သွင်းခွင့်" (Install unknown apps) မေးလျှင် ဤ browser / ဖိုင်မန်နေဂျာ အတွက် ခွင့်ပြု ကို ဖွင့်ပြီး ပြန်လာပါ။Open the downloaded file. If the phone asks about "Install unknown apps", turn on Allow for this browser / file manager, then go back.
  3. ထည့်သွင်း (Install / Update) ကို နှိပ်ပါ။ ဒေတာများ ဆက်ရှိနေပါမည်။Tap Install (or Update). Your data stays on the phone.
  4. ApexBOS ကို ဖွင့်ပြီး ဆက်တင် → အကြောင်း တွင် ဗားရှင်း 0.2.23 ဖြစ်ကြောင်း စစ်ပါ။Open ApexBOS and check Settings → About shows version 0.2.23.

  1. ဗားရှင်းဟောင်းထဲတွင် Backup လုပ်ပြီး ဖိုင်နှင့် စကားဝှက်ကို သိမ်းပါ။Make a Backup in the old app; keep the file and its password.

ငွေပေးချေနည်းHow to pay

စမ်းသပ်ကာလ — လက်ဖြင့် အတည်ပြုပါသည်Pilot — approved by hand

KBZPay၊ WavePay သို့မဟုတ် ဘဏ်လွှဲဖြင့် ပေးနိုင်ပါသည်။Pay by KBZPay, WavePay or bank transfer.

  1. အက်ပ်ထဲတွင် ဆက်တင် → Sync server plan → Connect sync server ကို ဖွင့်ပါ။In the app, open Settings → Sync server plan → Connect sync server.
  2. အစီအစဉ်ကို ရွေးပြီး ငွေပေးချေပါ။Choose a plan and pay.
  3. ငွေလွှဲ နံပါတ် (Transaction ID) ကို ထည့်ပါ။ ပြေစာ ဓာတ်ပုံလည်း ထည့်နိုင်ပါသည် (မဖြစ်မနေ မဟုတ်)။Enter the transaction ID. You can add a receipt photo (optional).
  4. Send request ကို နှိပ်ပါ။Tap Send request.
  5. ကျွန်ုပ်တို့ အတည်ပြုပြီးသည်နှင့် လက်မှတ်ထိုးထားသော key ရောက်လာပြီး အလိုအလျောက် ချိတ်ဆက်ပါမည်။Once we approve it, your signed key arrives and connects automatically.

Key ကို စာတို သို့မဟုတ် QR ဖြင့်လည်း ပို့နိုင်ပြီး Advanced တွင် ကူးထည့်နိုင်ပါသည်။ သက်တမ်းတိုးခြင်းလည်း ဤနည်းအတိုင်း ဖြစ်ပါသည်။A key can also be sent by text or QR and pasted under Advanced. Renewal works the same way.
